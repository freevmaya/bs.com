Список запросов API
Базовый URL: https://<ваш-домен>

Все запросы — GET, без авторизации, с CORS Access-Control-Allow-Origin: *.

1. Список производителей
text
GET /api/manufacturers
Возвращает производителей, у которых есть хотя бы одно active-крыло.

Пример:

bash
curl https://bs.com/api/manufacturers
Ответ:

json
{
  "success": true,
  "data": [
    {
      "id": 15,
      "name": "Ozone",
      "website": "https://flyozone.com",
      "layout_method": "roman",
      "wings_count": 42
    }
  ]
}
2. Список крыльев производителя
text
GET /api/manufacturers/{id}/wings
{id} — целое число, manufacturers.id.

Пример:

bash
curl https://bs.com/api/manufacturers/15/wings
Ответ:

json
{
  "success": true,
  "data": {
    "manufacturer": {
      "id": 15,
      "name": "Ozone",
      "website": "https://flyozone.com",
      "layout_method": "roman"
    },
    "wings": [
      {
        "id": 101,
        "source_id": 2026,
        "model": "Eazy",
        "model_year": 2013,
        "size": "M",
        "full_name": "Ozone Eazy (2013) M",
        "source_url": "https://we-measure.io/user/wing/map/2026",
        "catalog_match": true,

  }
}
Ошибка (404):

{ "success": false, "error": "Производитель не найден" }

Служебные ответы
Ситуация	HTTP-код	Тело
Не-GET запрос (POST, PUT…)	405	{ "success": false, "error": "Method Not Allowed" }
Preflight OPTIONS	204	(пусто)
Необработанное исключение	500	{ "success": false, "error": "Internal Server Error" }
CORS
Для всех ответов (включая ошибки) выставляются заголовки:

text
Access-Control-Allow-Origin: *
Access-Control-Allow-Methods: GET, OPTIONS
Access-Control-Allow-Headers: Content-Type, Accept
Типичный сценарий использования
GET /api/manufacturers → выбрать производителя, запомнить id.

GET /api/manufacturers/{id}/wings → выбрать крыло, запомнить id.

GET /api/wings/{id}/lines → получить длины строп.

Все три запроса можно делать напрямую из браузера (fetch) или из любого клиента — авторизация не требуется.
